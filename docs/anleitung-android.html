1Überblick

DEFINITION

PWA (Progressive Web App) = Web-App, die sich aus dem Browser wie eine App installieren lässt: eigenes Symbol, eigenes Fenster ohne Browserleiste und nach einmaligem Laden komplett offline nutzbar.

  • Kein Play Store, keine APK: installiert wird direkt aus Chrome.
  • Decks, Lernstände und Backups bleiben nur auf dem Gerät. Es gibt kein Konto und keinen Server, der Daten empfängt.
  • Einmal mit Internet öffnen, danach läuft alles im Flugmodus.
MERKE

Vier Schritte, die ersten beiden nur einmal: bereitstellen (Abschnitt 2) → installieren (3) → offline testen (4) → Decks importieren (5).

2App bereitstellen (einmalig, am Laptop)

ACHTUNG

Chrome speichert eine Web-App nur dann offline, wenn sie über https geladen wird. Eine Adresse aus dem WLAN wie http://192.168.x.x:4173 reicht dafür nicht.

Variante A: Netlify (am schnellsten)

  1. Im Projektordner lernkarten-app den Build erzeugen:
    npm run build
  2. Im Browser app.netlify.com/drop öffnen.
  3. Den Ordner dist aus dem Projektordner auf die Seite ziehen.
  4. Netlify zeigt eine Adresse wie https://irgendwas-123.netlify.app – das ist die App.

Ohne Konto ist eine Drop-Seite nur vorübergehend online und wird gelöscht, wenn man sie nicht mit einem kostenlosen Konto beansprucht. Mit Konto bleibt sie bestehen; unter Site configuration → Change site name lässt sich ein lesbarer Name vergeben, z. B. lernkarten-maik.netlify.app. Ergänzung: Netlify-Blog „Thirteen years of Netlify Drop“.

Variante B: GitHub Pages

  1. Projekt als Repository auf GitHub anlegen und hochladen.
  2. Im Repository Settings → Pages öffnen und bei Source „GitHub Actions“ wählen.
  3. Die Datei .github/workflows/pages.yml mit dem Inhalt von Seite anlegen und hochladen (push).
  4. Nach etwa einer Minute ist die App unter https://<benutzername>.github.io/<repository>/ erreichbar. Jeder weitere Push veröffentlicht automatisch die neue Version.

3Auf dem Handy installieren

  1. Chrome öffnen – nicht die Google-App und nicht den eingebauten Browser von WhatsApp oder E-Mail.
  2. Die Adresse aus Abschnitt 2 eingeben.
  3. Warten, bis unten kurz „Offline bereit“ erscheint. Erst dann ist alles im Gerät gespeichert.
  4. Oben rechts das Menü ⋮ öffnen → App installieren (auf manchen Geräten: Zum Startbildschirm hinzufügen → Installieren).
  5. Bestätigen. Das Lernkarten-Symbol liegt jetzt auf dem Startbildschirm bzw. in der App-Übersicht.
MERKE

Die App ab jetzt immer über das Symbol starten, nicht über einen Chrome-Tab.

Samsung Internet funktioniert ähnlich (Menü → Seite hinzufügen zu → Startbildschirm). Für „Bildschirm bleibt an“ und dauerhaften Speicher ist Chrome die sichere Wahl.

4Offline testen

ACHTUNG / VOR DER ERSTEN ZUGFAHRT

Den Test einmal zu Hause durchführen. Fehlt beim ersten Laden die Zeit zum Speichern, merkt man es sonst erst im Funkloch.

  1. App über das Symbol öffnen und in der leeren Deckliste Beispieldeck laden antippen (später wieder löschbar).
  2. Flugmodus einschalten.
  3. App komplett schließen (aus der Übersicht der offenen Apps wischen) und über das Symbol neu öffnen.
  4. Das Deck muss da sein; Lernen und Quiz müssen funktionieren.
  5. Flugmodus aus. Unter Einstellungen → Offline steht: „Die App ist auf diesem Gerät gespeichert und läuft ohne Internet.“

Klappt etwas nicht: siehe Abschnitt 9.

5Decks aufs Handy bringen

Die App liest Deck-Dateien (.json), Anki-/Quizlet-Textdateien (.txt, .tsv, .csv) und Bilder direkt aus dem Handyspeicher.

WegSo geht es
OneDriveIn der OneDrive-App die Deck-Datei antippen → ⋮ → Herunterladen (landet in Downloads). In der Lernkarten-App Deck importieren → Datei aus Downloads wählen.
Deck mit BildernBei "image": "bilder/…" die Bilder ebenfalls herunterladen und im Dateidialog zusammen mit der JSON-Datei markieren.
QuizletSet exportieren, Text kopieren, in der Deckliste Text einfügen (Quizlet/Anki).
Andere WegeE-Mail an sich selbst, USB-Kabel oder „Teilen“ aus einer anderen App.
MERKE

Nach der Installation einmal Einstellungen → Speicher → Dauerhaft speichern anfragen antippen. Dann löscht Android die Lerndaten nicht von sich aus, wenn der Speicher knapp wird.

6Lernen im Zug

FunktionWirkung
ZugmodusZug-Symbol oben beim Lernen und im Quiz (oder in den Einstellungen): größere Schrift, Bewertung im 2×2-Raster für den Daumen, Bildschirm bleibt an, solange gelernt wird.
Karte antippendeckt die Antwort auf – mit einer Hand bedienbar.
Speichernerfolgt sofort nach jeder Bewertung; die App darf jederzeit geschlossen werden.

Im Energiesparmodus kann Android das Anlassen des Bildschirms verweigern; dann geht er wie gewohnt aus.

7Laptop und Handy

Beide Geräte lernen getrennt: Jedes hat eigene Decks und Lernstände; es gibt keinen Server, der abgleicht.

ZielWeg
Gleiche Decks auf beidenDie Deck-Datei auf beiden Geräten importieren.
Lernstand umziehenLaptop: Einstellungen → Sicherung → Backup herunterladen; Datei aufs Handy bringen; dort Backup wiederherstellen.
Backup vom Handy sichernBackup teilen … legt es z. B. direkt in OneDrive ab.
ACHTUNG

Backup wiederherstellen ersetzt alles auf dem Zielgerät. Zwei Geräte werden nicht zusammengeführt.

8Updates

Nach einer neuen Version (Abschnitt 2 erneut) holt sich die App die Änderungen beim nächsten Start mit Internet selbst. Manchmal ist sie erst nach dem zweiten Öffnen aktuell. Decks und Lernstände bleiben bei Updates erhalten.

9Probleme und Lösungen

ProblemLösung
„App installieren“ fehlt im MenüÜber https geöffnet? Normale Chrome-App statt Browser in WhatsApp oder Google-App? Seite neu laden.
Offline nur „Keine Internetverbindung“Beim ersten Öffnen nicht lange genug online: mit Internet öffnen, „Offline bereit“ abwarten, erneut testen.
Decks sind plötzlich wegNach Deinstallation oder Löschen der Website-Daten von Chrome. Deshalb regelmäßig ein Backup – die Deckliste erinnert nach 14 Tagen.
Bildschirm geht trotz Zugmodus ausEnergiesparmodus aus oder die Bildschirm-Zeit von Android hochsetzen.
Datei lässt sich nicht auswählenÜber ☰ → Downloads oder OneDrive suchen; manche Dateimanager zeigen .json erst bei „Alle Dateien“.

Quelle: Lernkarten-App, docs/ANDROID.md („Probleme“)

10iPhone und APK

  • iPhone: Safari → Teilen → Zum Home-Bildschirm; offline genauso. iOS kann Web-App-Daten nach mehreren Wochen ohne Nutzung löschen – Backup!
  • APK: kein Vorteil fürs Lernen im Zug. Über Capacitor wären Android Studio und das SDK nötig; bewusst nicht gebaut, nachrüstbar.

Quelle: Lernkarten-App, docs/ANDROID.md („iPhone“, „Und eine echte APK?“) · docs/ENTSCHEIDUNGEN.md (Android, Phase 5)

11Das Wichtigste in Kürze

MERKE
  • Web-App aus Chrome statt Play Store oder APK.
  • Nötig ist eine https-Adresse (Netlify oder GitHub Pages).
  • „Offline bereit“ abwarten, dann ⋮ → App installieren.
  • Vor der ersten Fahrt im Flugmodus testen.
  • Decks aus OneDrive laden, dauerhaften Speicher anfragen.
  • Geräte lernen getrennt; Wiederherstellen ersetzt alles.
